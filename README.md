# Marwan Kamal Hafez — Portfolio

## 🌐 Live Demo
👉 [Visit Portfolio](https://marwanfolio-gntffftf.manus.space/)

## 📋 Overview
A modern, single-page portfolio website built with React and Tailwind CSS, showcasing my expertise as an AI & Machine Learning Engineer. The portfolio features a dark-themed professional design with smooth animations, interactive elements, and clear project presentations.

## ✨ Features
- **Hero Section** — Animated typewriter greeting in 7 languages with profile photo
- **Tech Skills** — Animated progress bars for Python, ML, Deep Learning, Web Development, and Tools
- **Soft Skills** — Visual cards showcasing leadership, communication, and problem-solving abilities
- **Projects** — Featured work with screenshots, tech stack, and live links
- **Education** — Timeline of academic background and certifications
- **Certificates** — Clickable certificate cards with lightbox preview and PDF download
- **Contact Form** — Direct messaging with Name, Email, and Message fields

## 🛠️ Tech Stack
| Category | Technologies |
|----------|-------------|
| Frontend | React 19, Tailwind CSS 4, Framer Motion |
| UI Components | shadcn/ui, Lucide Icons |
| Routing | Wouter |
| Styling | Custom dark theme with glassmorphism effects |

## 📂 Project Structure
```
client/
├── public/          # Static assets
├── src/
│   ├── pages/       # SinglePagePortfolio.tsx
│   ├── components/  # Reusable UI components
│   ├── hooks/       # Custom React hooks
│   ├── contexts/    # Theme context
│   └── index.css    # Global styles & animations
```

## 🚀 Getting Started

```bash
# Install dependencies
pnpm install

# Run development server
pnpm dev

# Build for production
pnpm build
```
